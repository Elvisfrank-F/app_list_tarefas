# 📋 Lista de Tarefas

Um aplicativo moderno e intuitivo para **organização de tarefas**, com suporte a **múltiplas listas**, **sincronização em nuvem** e **exportação em PDF**. Desenvolvido com foco em produtividade, simplicidade e segurança dos dados.

---

## ✨ Funcionalidades

### 🗂️ Gerenciamento de Listas

* Crie **múltiplas listas de tarefas**
* Nomeie suas listas conforme sua necessidade
* Edite listas já existentes
* Navegue facilmente entre diferentes listas

#### ☁️ Sincronização em Nuvem (Firebase)

* Upload automático das tarefas para o banco de dados em nuvem
* Download das tarefas da nuvem para o dispositivo local
* Garantia de persistência e segurança dos dados

---

### 📄 Exportação em PDF

* Converta suas listas de tarefas em **PDF**
* Ideal para impressão, compartilhamento ou arquivamento

---

## 🚀 Objetivo do Projeto

Este aplicativo foi desenvolvido com o objetivo de aplicar boas práticas de desenvolvimento mobile, arquitetura organizada e integração com serviços em nuvem, servindo tanto como **ferramenta prática** quanto como **projeto de portfólio profissional**.
